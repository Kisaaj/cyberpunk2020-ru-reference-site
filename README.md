# Cyberpunk 2020 Помогалка на русском

Данный сайт, созданный с помощью демонической силы нейрослопа, представляет из себя удобный сборник все возможного контента из официального рулбука Cyberpunk 2020 и дополнений вышедших к нему. 
Идея родилась очень просто. Уже существуют в мире такие замечательные места как dnd.su, посвященных D&D 5e. Безусловно, D&D куда популярнее Cyberpunk 2020, но чем он хуже иметь собственный сайт? Тем более, который существует полностью на русском языке. 
Все подобные варианты уже существующие в интернете, во-первых, на английском языке, который может быть понятен далеко не каждому русскоговорящему человеку на Земле. Во-вторых, эти англичанские сайты, в основном, посвящены своим собственным homebrew (хоумрулам), которые, конечно, крутые местами. Но, по большей части, это не то, что ищет простой пользователь когда создаёт своего киберпанка.
Вот оно и родилось.

# Правовая часть

Права на все используемые здесь материалы и информацию принадлежат компании R. Talsorian Games. Сайт не распространяет пиратские копии официальных книг, а является лишь справочным сборником, существующим исключительно для удобства людей.
Сайт существует не для заработка денег и, в теории, никогда не должен монетезироваться. Если когда-нибудь этот день придёт, значит настали тяжёлые времена...
